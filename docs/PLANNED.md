# Отложенные идеи

## Управление zapret — реализовано локально по запросу пользователя

Отдельный пункт под историей в левой панели: выбор папки Flowseal, стратегии, включение, выключение, перезапуск, фильтры, пользовательские списки и последние действия. Проверена структура установленной сборки Flowseal 1.10.4.

«Выключать zapret при подключении VPN» выключено по умолчанию. При отключённой функции подключение сопровождается неблокирующим предупреждением о возможном конфликте и подсказкой, где включить автоотключение. Дополнительная настройка возвращает только тот экземпляр, который приложение само остановило; изначально выключенный zapret не запускается.

Управление ограничено выбранной папкой, PID и временем создания процесса либо проверенной службой. Действия с правами администратора проходят через отдельный процесс с проверкой канала. BAT-меню, удаление общих драйверов и сторонних VPN не выполняются.

## Отложено: одновременная фильтрация zapret и TUN

Нужна отдельная проверка фильтров на конкретной стратегии: работа с прямым трафиком, исключение VPN-соединения и внутреннего трафика TUN при смене сервера. Текущая интеграция управляет состоянием zapret, не обещает автоматическое устранение всех конфликтов и не меняет его фильтры для совместной работы с TUN.
