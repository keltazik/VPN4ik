VPN4ik — VPN-клиент с бордово-золотым интерфейсом и орнаментом вместо обычной кнопки подключения. Импортируй подписку, выбери сервер и подключайся. Приложение проверяет соединение, показывает скорость и сохраняет историю сеансов.

> [!NOTE]
> **Текущая версия — 1.0.0-beta.6 для Windows x64.** Это предварительный выпуск.

В этой версии объединены обновление по кнопке, исправление смешанных подписок, увеличенные значки управления окном и подпись **keltazik**. Настройки и подписки существующего пользователя сохраняются.

Открой **[страницу актуального выпуска](https://github.com/keltazik/VPN4ik/releases/tag/v1.0.0-beta.6)** и выбери файл в разделе **Assets**:

Автоматические архивы **Source code** содержат исходники. Для запуска приложения нужен ZIP с названием **VPN4ik**.

Распакуй **всю папку** и запусти **`VPNyan.exe`**. Это внутреннее имя исполняемого файла VPN4ik. Устанавливать .NET отдельно не требуется: среда выполнения уже включена. Папка `Engine` должна оставаться рядом с программой.

**Новое в beta.6:** плашка «Доступно обновление» скачивает и проверяет новый выпуск после нажатия, затем перезапускает приложение; при недоступной автоустановке открывается релиз в браузере. Служебная маршрутизация INCY/Happ больше не мешает импорту серверов. Значки сворачивания, разворачивания и закрытия стали крупнее, получили общий стиль и точное центрирование. Подпись в боковой панели — **keltazik**. .NET Desktop Runtime и WPF встроены прямо в EXE; установка .NET не нужна. Файл `BUILD-INFO.json` в архиве содержит коммит и SHA-256 программы для сверки с `VPN4ik-routing`.

### Как обновляться

В beta.4 и новее приложение проверяет опубликованные релизы при запуске и каждые четыре часа. Когда доступна новая версия, нажми **«Обновить»** на небольшой плашке: после загрузки и проверки собственный VPN отключится, программа установит новую сборку и перезапустится. Подписки и настройки сохраняются. Автоматически скачивать и устанавливать файлы без нажатия приложение не будет. Ручная проверка и переключатель автопроверки находятся в **Настройки → Основные**.

Если у тебя beta.3 или более ранняя версия, один раз скачай новый ZIP вручную: в этих версиях механизма обновлений ещё нет.
## Быстрый старт

1. Закрой прежнюю версию VPN4ik, если она запущена.
2. Запусти `VPNyan.exe` из распакованной папки.
3. Нажми **＋ Добавить** на левой панели и импортируй свою HTTPS-подписку или конфигурацию.
4. Открой **Серверы** и выбери нужный сервер.
5. Нажми на орнамент и подтверди запрос Windows на запуск VPN-службы.
6. Дождись статуса **«Подключено»**. Повторное нажатие на орнамент отключает VPN.

Сервисы и серверы в комплект не входят: нужна собственная действующая подписка или конфигурация. Приватные ключи и ссылки доступа в репозитории отсутствуют.

## Интерфейс

Бордовая палитра, золотые акценты и настройки с автосохранением. Боковая панель открывает серверы, импорт, настройки, журнал и историю.

На странице **Добавить** под полями импорта перечислены добавленные подписки и файлы конфигурации. Кнопка **Удалить** убирает источник со всеми его серверами. ПКМ по серверу открывает подключение, тест пинга, копирование, редактирование и удаление одного профиля. Удалённый профиль остаётся скрытым при обновлении той же подписки. Активный сервер можно сменить обычным выбором в списке: приложение остановит прежнее соединение и подключит новое. Краткий разрыв соединения при этом ожидаем.

### Раздельное туннелирование

Открой **Настройки → Маршрутизация**. Добавь приложения через выбор `.exe`, список **«Из запущенных процессов»** или введи имя процесса/полный путь. Если Windows скрывает путь процесса, сохраняется его имя `.exe`. Домены и подсети добавляются по одному правилу на строку.

- **Выбранное без VPN:** совпавшие приложения, сайты и IP идут напрямую; остальное — через VPN.
- **Только выбранное через VPN:** совпавшее идёт через VPN; остальное — напрямую.

Правила разных списков объединяются по принципу «или». Включённый обход локальной сети имеет приоритет. Изменения сохраняются автоматически и применяются **после переподключения**.

**Основные** — запуск, автоподключение, трей и уведомления. **Соединение** — MTU, DNS и локальная сеть. **Маршрутизация** — правила разделения трафика. **Интерфейс** — единицы скорости и расписание проверки пинга.

## Поддержка и ограничения

- Основная платформа — **Windows x64**. Android и iOS пока не выпущены.
- Xray-профили: VLESS, VMess, Trojan, Shadowsocks, SOCKS и Hysteria2, с поддерживаемыми транспортами TCP/gRPC/WebSocket и TLS/Reality. Расширенные параметры XHTTP и маскировка Hysteria2 пока не поддерживаются.
- WireGuard `.conf` обслуживается отдельной службой. Для него маршрутизация задаётся через `AllowedIPs`; правила приложений/доменов в интерфейсе относятся к Xray. Состояние WireGuard-службы не выдаётся за проверенный handshake.
- Доменные правила могут не распознавать имя сайта при ECH. В таком случае используй приложение или IP.
- Полноценный Kill Switch и восстановление после сна пока не реализованы. Для автоустановки обновления нужна возможность записи в папку приложения; при недоступной автоустановке предлагается страница релиза.
- Это переносимая сборка; установщик не входит в релиз.

## Сборка из исходников

Нужны Windows x64, Git и **.NET SDK 10** (проект приложения использует .NET 8, проверки — .NET 10).

```powershell
git clone https://github.com/keltazik/VPN4ik.git
cd VPN4ik
powershell -NoProfile -File build.ps1
```

Скрипт скачает закреплённый Xray из официального релиза, проверит архив и подпись Wintun, затем создаст автономную сборку в `artifacts/VPN4ik-routing/`. Переносить нужно всю папку.

```powershell
# Проверки логики и размеров интерфейса: без сети и без TUN
powershell -NoProfile -File checks/run.ps1

# Настоящий Xray на локальных серверах: только loopback, без TUN
powershell -NoProfile -File checks/run.ps1 -NativeRouting
```

По результатам Windows-проверок, указанным в [истории выпуска](CHANGELOG.md), версия **1.0.0-beta.6** прошла **378 локальных проверок + 13 проверок Xray**. Последовательность переключения и обработка ошибок проверяются с подставным сеансом; установка и откат обновления — на изолированной копии настоящего EXE. Эти проверки не меняют системные маршруты. Запуск приложения и этих проверок требует Windows; Linux-среда подходит для редактирования и компиляции с Windows targeting packs. Подробности — в [документации разработчика](docs/DEVELOPMENT.md).

Профиль `Portable` встраивает .NET и WPF внутрь EXE, а `Engine` остаётся рядом. Сборка и упаковка копируют только EXE и Engine в чистую папку и проверяют отрисовку WPF без установленного .NET.
## Данные и компоненты

Подписки, история и логи хранятся локально; ключи защищены для текущего пользователя Windows. Не добавляй свои `.conf`, `.dpapi`, токены и ссылки подписок в Git. Для сообщения об ошибке используй [Issues](https://github.com/keltazik/VPN4ik/issues) и убери из вложений данные доступа.

Лицензии Xray, Wintun, WireGuard и среды .NET описаны в [THIRD_PARTY.md](THIRD_PARTY.md). Компоненты и их уведомления включены в архив релиза.
