# История изменений

## Локальная сборка 2 для beta.6 · не опубликована

- Добавлен ограниченный по глубине, времени и количеству папок автопоиск zapret: сохранённый путь, процессы, службы, загрузки, рабочий стол, документы и локальные диски. При нескольких установках доступен список; ручной выбор папки остаётся рядом.
- Пункты Flowseal service.bat 1.10.4 перенесены во вкладку: Game Filter с отдельными списками портов TCP/UDP, IPSet, флаг автопроверки обновлений, замена Discord/Game active fakes с резервной копией, установка и удаление службы выбранной папки.
- Добавлены загрузка IPSet с проверкой содержимого и сохранением режима фильтра, предпросмотр hosts для ручного переноса, проверка версии zapret и переход на релиз разработчика.
- Диагностика читает состояние служб, прокси, конфликтующих компонентов и TCP. Включение TCP timestamps выполняется отдельной кнопкой. Тест стратегий проверяет HTTPS YouTube/Discord, запрещён при активном VPN4ik и возвращает прежние процессы и команду службы после завершения или ошибки.
- Интеграция не запускает исходные BAT/PowerShell-меню, не удаляет общие драйверы WinDivert и не останавливает другие VPN. Установка/удаление службы и реальная фильтрация требуют проверки на целевой Windows с правами администратора; локальные проверки используют подставные процессы и изолированные папки.
- GitHub и публичная beta.6 не изменены; локальная версия обозначена `1.0.0-beta.6+local.2`.
- 445 локальных проверок, проверка настоящих тестовых процессов без WinDivert и чтение установленной папки. Автопоиск на целевом ПК нашёл Flowseal примерно за 0,5 секунды.

## Локальная сборка 1 для beta.6 · не опубликована

- Добавлена отдельная вкладка zapret внизу левого меню: папка Flowseal, 22 стратегии установленной сборки 1.10.4, статус, включение, выключение, перезапуск и открытие папки.
- Добавлены настройки игрового фильтра и IPSet, пользовательские доменные/IP-списки с автосохранением и резервными файлами, журнал действий. Изменение списков и фильтров применяется к работающему zapret после перезапуска.
- «Выключать zapret при подключении VPN» по умолчанию выключено. При подключении показывается неблокирующее предупреждение и подсказка о функции автоотключения.
- При включённой функции VPN ждёт подтверждённой остановки выбранного zapret. Опционально возвращается прежний запуск после отключения или ошибки VPN; при смене сервера zapret остаётся выключенным. Изначально выключенный экземпляр не запускается.
- Запуск и остановка ограничены выбранной папкой, проверенными службами, PID и временем создания процесса. Для привилегированных действий используется отдельный проверенный процесс. Другие установки и VPN не останавливаются, драйвер WinDivert не удаляется.
- Номер публичной beta не повышен: GitHub остаётся на beta.6. Следующая публикация потребует отдельного запроса пользователя и получит beta.7.
- 419 локальных проверок. Дополнительно проверены запуск, захват параметров, остановка и возврат реальных тестовых процессов без WinDivert, защита экземпляра из другой папки и чтение всех 22 стратегий установленной сборки 1.10.4.

- Увеличены и отцентрированы векторные значки сворачивания, разворачивания и закрытия окна. Единый золотой цвет, аккуратная подсветка фоном и красная кнопка закрытия при наведении.

- Смешанные подписки с серверными ссылками и маршрутизацией INCY/Happ импортируются с сохранением собственных настроек VPN4ik.
- 378 локальных проверок, 13 проверок Xray через loopback и проверка установки/отката на изолированной копии автономного EXE. .NET 8.0.31 и WPF встроены в приложение.
- Пользователям beta.3 и старше нужно один раз установить ZIP вручную; beta.4/beta.5 уже умеют получать новую версию через плашку.

## 1.0.0-beta.5 · исправление смешанных подписок, включено в beta.6

- Исправлен импорт подписок, в которых рядом с VLESS-ссылками есть служебная маршрутизация `incy://routing/...`, `autorouting` или аналогичные строки Happ. Раньше такая строка прерывала импорт всех серверов.
- Строки маршрутизации отделяются от серверов, включая подписки в base64. Приложение сообщает, что используются собственные настройки VPN4ik; внешние настройки и URL из таких строк не применяются и не загружаются.
- Подписки только со служебными настройками, неизвестные форматы и некорректные серверы по-прежнему отклоняются с сохранением прежнего списка.
- Пройдены 378 локальных проверок. Настоящий ответ проблемной подписки распознан как один VLESS-сервер и одна служебная строка; сформированная конфигурация принята закреплённым Xray без TUN.
- Идея управления zapret сохранена в `docs/PLANNED.md` без реализации.

## 1.0.0-beta.4 · подготовлено локально, включено в beta.6

- Небольшая плашка «Доступно обновление» с кнопкой обновления и закрытием на текущий сеанс.
- Анонимная проверка опубликованных GitHub Releases через четыре секунды после запуска и каждые четыре часа. Учитываются beta-выпуски и числовой порядок версий; обычные коммиты и черновики не предлагаются.
- В основных настройках добавлены текущая версия, ручная проверка и переключатель автопроверки с автосохранением.
- После нажатия обновление скачивается по HTTPS, сверяется с SHA-256 GitHub, проверяется состав архива, версия EXE, манифест и запуск со встроенным .NET.
- Отдельный установщик ждёт штатного закрытия приложения, сохраняет прежние файлы и заменяет только файлы сборки. Ошибка проверки запуска вызывает откат. Подписки, настройки, конфиги, логи и история не входят в замену.
- Для выпуска без контрольной суммы или при недоступной автоустановке кнопка открывает страницу релиза на GitHub. Без нажатия ничего не скачивается и не устанавливается.
- Кратковременная блокировка файлов Windows обрабатывается повторными попытками без остановки сторонних процессов. Пройдены 352 локальные проверки, включая эту блокировку, защиту архива и откат.

## 1.0.0-beta.3 · управление серверами, 26 октября 2026

- Добавлена собственная бордово-золотая иконка EXE, окна Windows и системного трея.
- На странице импорта перечислены добавленные подписки и конфиги, доступны обновление и удаление источника.
- ПКМ по серверу открывает меню подключения, пинга, копирования, редактирования и удаления. Удаление одного профиля не затрагивает остальные и сохраняется после обновления подписки.
- Выбор другого сервера при активном VPN запускает переподключение. Новое соединение ждёт подтверждённой остановки прежнего; при ошибке остановки сохраняется старое подключение.
- Рядом с пингом и обновлением добавлена сортировка по имени, стране, пингу, протоколу и исходному порядку. Выбранный порядок сохраняется автоматически.
- В раздельном туннелировании можно выбрать приложения из списка запущенных процессов, включая поиск по имени и пути.
- Убрано размытие орнамента при наведении; в раскрытой панели добавлена подпись Sarik.
- Внизу настроек добавлен полный сброс с подтверждением: отключение VPN, удаление подписок, конфигов, логов, истории и возврат настроек к исходным.
- 320 локальных проверок, включая изолированное хранилище, отмену сброса, ошибки переключения и отрисовку новых окон; 13 проверок настоящего Xray через loopback. Переключение проверено с подставным сеансом, без изменения TUN и маршрутов.

## 1.0.0-beta.2 · исправление запуска, 26 октября 2026

- .NET Desktop Runtime и WPF встроены в исполняемый файл автономной сборки; отдельная установка .NET не нужна.
- Добавлен профиль публикации `Portable`, проверка запуска и отрисовки из чистой папки с загрузкой встроенного runtime.
- Упаковка отклоняет обычную сборку из `bin` и использует новую папку подготовки для каждого архива.
- Исправлен импорт смешанных подписок: добавлен формат Xray Hysteria2 (`protocol: hysteria`, `settings.address/port`) и ссылки `hy2://` / `hysteria2://`.
- Реальная подписка с 44 профилями проверена: 37 VLESS и 7 Hysteria2 распознаны и приняты закреплённым Xray.
- Служебные direct/block/DNS-профили больше не прерывают импорт остальных серверов.
- Сохранены последние локальные изменения: векторный орнамент, флаги стран, выравнивание подсказок и TCP-пинг при включённом VPN с предупреждением о точности. Для UDP-профилей показывается отметка UDP вместо ложного TCP-тайм-аута.
- В архив добавлен `BUILD-INFO.json` с коммитом исходников и SHA-256 исполняемого файла для проверки соответствия папке `VPN4ik-routing`.

## 1.0.0-beta.1 · 25 октября 2026

Первый собранный выпуск VPN4ik для Windows x64.

- Подключение через Xray TUN с IPv4/IPv6 и проверкой доступности.
- Импорт подписок и конфигураций, поиск и выбор серверов.
- Бордово-золотой интерфейс с орнаментом и выдвигающейся навигацией.
- Настройки с автосохранением: основные, соединение, маршрутизация и интерфейс.
- Раздельное туннелирование по приложениям, доменам и IP/CIDR в двух режимах.
- Статистика VPN из счётчиков Xray; обновление скорости раз в секунду, Mbps/MB/s.
- TCP-пинг с блокировкой при активном TUN.
- Журнал событий и история подключений внутри приложения.
- Защита подписок и истории средствами Windows DPAPI.
- 208 локальных проверок и 12 проверок настоящего Xray через loopback.

Известные ограничения: Windows x64, без автоматического обновления и полноценного Kill Switch. Правила раздельного туннелирования доступны для Xray; WireGuard использует AllowedIPs своего файла. Hysteria2 и расширенные параметры XHTTP не поддерживаются.
