# Работа с VPN4ik

- Изменения и сборки выполняются локально. Не отправляй коммиты или теги, не создавай и не изменяй релизы и не загружай файлы на GitHub без прямого запроса пользователя на публикацию. Обычная просьба доработать приложение разрешением на публикацию не является.
- Для приложения используется `source/VPNyan/VPNyan`, актуальная папка запуска — `artifacts/VPN4ik-routing`. Перед заменой работающей сборки нужно штатно закрыть только VPN4ik и сохранить резервную копию. Другие VPN не останавливать.
- Не добавляй в Git ссылки доступа, ключи, пользовательские конфиги и содержимое DPAPI-хранилищ. Проверки выполняются на изолированных данных.
- Основные проверки: `powershell -NoProfile -File checks/run.ps1`. Автономная сборка: `powershell -NoProfile -File build.ps1 -OutputDirectory artifacts/VPN4ik-updates`.
